# Preview tampilan per modul

Preview berjalan langsung dari aplikasi, bukan screenshot statis. Jalankan `npm install` lalu `npm run dev`.

| Modul | Yang akan terlihat |
|---|---|
| Navbar | Sidebar SaaS, topbar, pencarian menu, notifikasi, profil admin |
| Landing Page PPDB | Hero gradasi biru, aksen kuning, periode PPDB, kartu program, CTA |
| Form Pendaftaran | Form data diri responsif dengan field calon santri |
| Upload Berkas | Empat area pemilihan file, indikator kelengkapan, tips dokumen |
| Form Pembayaran | Rincian biaya dummy, pilihan metode, input bukti pembayaran |
| Cetak Kartu Pendaftaran | Kartu beridentitas, nomor pendaftaran, data program, QR dekoratif, tombol print |
| Login Admin | Panel branding dan form login simulasi |
| Dashboard Admin | KPI, grafik aktivitas, donat status, tabel pendaftar terbaru |
| Tabel Data Pendaftar | Tabel, pencarian nama/nomor, filter status, tombol ekspor dummy |
| Validasi Berkas & Pembayaran | Tab pemeriksaan, kartu item, aksi setujui/revisi simulasi |
| WhatsApp Gateway | Nomor tujuan, template, editor pesan, log simulasi |
| Laporan Rekapitulasi | KPI, distribusi program, rekap status, cetak browser |
| Footer | Identitas Ponpes Humairah, label prototype dan tautan informasi |

Semua data bersifat dummy. Beberapa aksi menggunakan alert atau state lokal sebagai simulasi dan tidak menyimpan data permanen.
